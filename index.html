1. สร้างคำสั่ง

เลือก MOVE, RIGHT, LEFT หรือ STOP เพื่อสร้าง Program

2. ใช้ Loop / IF

3. กด RUN

Robot จะทำตามคำสั่งที่สร้างไว้

4. ผิดก็แก้ได้

ถ้ายังไม่ถึง Goal ให้ดู Hint/Debug แล้วลองใหม่
